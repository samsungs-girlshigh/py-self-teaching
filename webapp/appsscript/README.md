# 앱스 스크립트(백엔드) 설치 방법

## 1. 구글 시트 준비
1. 새 구글 시트를 하나 만듭니다. (예: "코드대륙모험기_기록")
2. 이 시트에는 다음 탭들이 자동으로 만들어집니다 (직접 만들 필요 없음): `학생명단`, `설정`, 그리고 각 스테이지 이름(`stage1_variables` 등)의 탭.
3. `학생명단` 탭에는 **정답율 계산의 분모**로 쓸 전체 학생 명단을 미리 입력해 두세요.
   - 헤더: `학년 | 반 | 번호 | 이름` (스크립트가 처음 만들 때 헤더가 자동 생성됩니다. 그 아래에 학생을 한 줄씩 채워 넣으세요.)

## 2. 스크립트 붙여넣기
1. 시트 메뉴에서 **확장 프로그램 → Apps Script** 를 클릭합니다.
2. 기본으로 열린 `Code.gs` 내용을 모두 지우고, 이 프로젝트의 `appsscript/Code.gs` 내용을 그대로 붙여넣습니다.
3. 저장합니다. (Ctrl+S)

## 3. 관리자 PIN 설정
1. Apps Script 편집기 상단에서 함수 선택 드롭다운을 `setupAdminPin` 으로 바꿉니다.
2. `Code.gs` 안의 `setupAdminPin()` 함수에서 `"1234"` 부분을 원하는 PIN으로 바꿉니다.
3. **실행** 버튼을 누릅니다. (최초 실행 시 권한 승인 화면이 뜨면 본인 계정으로 승인)
4. 실행이 끝나면 이 함수는 다시 실행할 필요 없습니다. (PIN을 바꾸고 싶을 때만 값 수정 후 재실행)

## 4. 웹앱으로 배포하기
1. 우측 상단 **배포 → 새 배포**를 클릭합니다.
2. 유형 선택에서 톱니바퀴를 눌러 **웹 앱**을 선택합니다.
3. 설정:
   - 설명: 아무거나 (예: v1)
   - **실행 계정: 나(본인 구글 계정)**
   - **액세스 권한이 있는 사용자: 모든 사용자**
4. **배포**를 클릭하고, 권한 승인을 진행합니다.
5. 배포가 끝나면 나오는 **웹 앱 URL**을 복사합니다.

## 5. 프론트엔드에 연결하기
`assets/js/config.js` 파일을 열어 아래 줄을 방금 복사한 URL로 바꿉니다.

```js
const APPS_SCRIPT_URL = "여기에_배포된_앱스스크립트_웹앱_URL을_붙여넣으세요";
```

## 6. 코드 수정 후 재배포할 때 주의
`Code.gs` 내용을 수정한 뒤에는 **배포 → 배포 관리 → 수정(연필 아이콘) → 새 버전 → 배포** 순서로 다시 배포해야 변경 사항이 실제 URL에 반영됩니다. (URL은 그대로 유지됩니다)

## 알아두면 좋은 점
- 이 파일럿은 PIN 코드로 교사 화면(허브 관리자/대시보드)을 보호하는 방식입니다. 더 강력한 보호가 필요하면, 이후 구글 로그인(Google Identity Services)로 특정 교사 이메일만 허용하는 방식으로 업그레이드할 수 있습니다.
- `ANSWER_KEY` 객체(Code.gs 상단)를 수정하면 정답을 바꿀 수 있습니다. 스테이지/문항을 추가하면 이 객체에도 함께 추가해야 채점이 됩니다.
- 동시에 여러 학생이 제출해도 데이터가 꼬이지 않도록 `LockService`로 처리되어 있습니다.
